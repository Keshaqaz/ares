# Автоматическое применение сбросов лимита

Термины для обсуждения решения, доступного пользователям ChatGPT с выданными одноразовыми сбросами.

## Language

**Выданный сброс**:
Одноразовое право пользователя сбросить допустимое окно лимита использования. Может иметь срок, после которого его нельзя применить.
_Avoid_: Обычное обновление лимита, денежные кредиты.

**Пятичасовая квота**:
Допустимый объём обычного использования в пятичасовом окне. Её исчерпание
само по себе не означает исчерпание недельной квоты.
_Avoid_: Недельный лимит, общий ноль без указания окна.

**Недельная квота**:
Допустимый объём обычного использования в недельном окне. Её состояние
рассматривается отдельно от состояния пятичасовой квоты.
_Avoid_: Пятичасовой лимит, срок активации сброса.

**Исчерпание квоты**:
Расходование доступного объёма конкретного окна до его обычного обновления.
Для недельного и пятичасового окон исчерпание фиксируется отдельно.
_Avoid_: Истечение лимита, обычное обновление лимита, истечение сброса.

**Общие правила**:
Выбранные пользователем условия автоматического применения, действующие сразу на все
выданные сбросы: «за 30 минут до истечения» и «автоприменение при исчерпании недельной
квоты». Правила независимы; оба выключены по умолчанию.
_Avoid_: Настройки отдельного сброса.

**Автоприменение при исчерпании недельной квоты**:
Общее правило: при подтверждённом исчерпании недельной квоты до её обычного обновления
применить выданный сброс с ближайшим сроком активации.
_Avoid_: Автоприменение при любом нуле, применение после восстановления лимита.

**Наблюдение за недельной квотой**:
Учащённые проверки состояния недельной квоты в течение часа после чтения, показавшего
99% её использования. Само по себе не разрешает применение сброса.
_Avoid_: Применение при 99%.

**Правило за 30 минут до истечения**:
Общее правило: начинать попытки применения каждого выданного сброса за 30 минут до
окончания срока его активации, без условия исчерпания недельной квоты.
_Avoid_: Интервал до истечения выбранного сброса.

**Срок активации**:
Последний момент, до которого выданный сброс можно применить.
_Avoid_: Дата обновления лимита.

**Применение сброса**:
Использование одного выданного сброса для восстановления доступного лимита.
_Avoid_: Покупка кредитов.

**Обычное обновление лимита**:
Восстановление лимита по расписанию продукта, без использования выданного сброса.
_Avoid_: Применение сброса.

**Интервал до истечения**:
Выбранное пользователем время между целевым моментом применения сброса и окончанием срока его активации.
_Avoid_: Оптимальный момент, накануне.

**Целевой момент применения**:
Выбранный момент начала попыток применить выданный сброс. При известном сроке активации определяется сроком и выбранным пользователем интервалом до истечения; не означает гарантированный момент успешного применения.
_Avoid_: Гарантированное время сброса.

**Группа совпадающих сроков**:
Выданные сбросы, сроки активации которых приходятся на одну календарную минуту. Для автоматического применения из такой группы выбирается один сброс.
_Avoid_: Сбросы с разницей меньше минуты.

**Применить сейчас**:
Подтверждённое действие пользователя, переносящее начало попыток применения выбранного сброса на текущий момент и заменяющее его прежнее расписание. Не зависит от общих правил и исчерпания недельной квоты. Не означает гарантированное немедленное восстановление лимита.
_Avoid_: Мгновенный гарантированный сброс.

**Цикл попыток применения**:
Последовательность попыток применить один выбранный выданный сброс с заданного момента до успеха или границы прекращения. Ручной повтор после завершения неуспешного цикла начинает новый цикл.
_Avoid_: Один сброс за каждую попытку.

**Бесплатный сервис**:
Сервис, который не берёт с пользователя плату за автоматическое применение выданных сбросов. Бесплатность сервиса не определяет стоимость подписки ChatGPT или открытость кода.
_Avoid_: Бесплатный ChatGPT, открытый исходный код.

**Открытый код сервиса**:
Исходный код сервиса доступен пользователям для изучения и проверки. Открытость кода сама по себе не определяет цену сервиса или необходимость самостоятельно его размещать.
_Avoid_: Бесплатный сервис, самостоятельное размещение.

**Внешний таймер**:
Сторонний бесплатный планировщик вне инфраструктуры исполнения, который в моменты опубликованных окон только будит приватную установку обычным запуском. Не хранит сессию ChatGPT, не решает о применении сброса и не передаёт команд.
_Avoid_: Исполнитель, сервер сброса, расписание GitHub.

**Токен установки**:
Единственный токен, который пользователь выпускает сам: доступ к приватному репозиторию установки и чтение собственного billing, со сроком до 366 дней, заданным при выпуске, и напоминанием о ротации. Пользователь выбирает репозиторий сам; более широкий доступ допускается с предупреждением. Хранится в секретах репозитория и в связке ключей macOS. Внешнему таймеру не передаётся.
_Avoid_: Основной PAT, billing-токен, токен таймера.

**Приложение таймера**:
Принадлежащее пользователю приложение GitHub, устанавливаемое на приватный репозиторий установки (более широкая установка допускается с предупреждением), с правами только на запуск установки и чтение опубликованных окон. Внешний таймер получает через него кратковременный доступ перед каждым запуском.
_Avoid_: Токен таймера, второй токен.

**Ключ таймера**:
Закрытый ключ приложения таймера, хранящийся только у внешнего таймера. Не имеет срока действия; при утечке отзывается в GitHub. Не позволяет передавать команды установке.
_Avoid_: Токен таймера, токен установки.

**Резервный запуск**:
Редкий запуск установки по собственному расписанию исполнителя, который восстанавливает состояние и сообщает, что внешний таймер давно не будил установку. Не является плановой попыткой цикла и не заменяет обнаружение новых сбросов.
_Avoid_: Плановая попытка, основной таймер, обнаружение сбросов.
