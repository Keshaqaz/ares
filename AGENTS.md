## Agent skills

### Issue tracker

Задачи хранятся в локальном Markdown-трекере `.scratch/<feature>/`. Перед чтением или публикацией задач прочитайте `docs/agents/issue-tracker.md`.

### Triage labels

Используются пять стандартных triage-меток. Перед triage прочитайте `docs/agents/triage-labels.md`.

### Domain docs

Используется single-context: корневой `CONTEXT.md` и `docs/adr/`. Перед изучением проекта прочитайте `docs/agents/domain.md`.
