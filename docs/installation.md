# Установка и использование

[English](installation.en.md) · **Русский**

## Что понадобится

- Mac на macOS. Сам воркер работает в GitHub, Mac нужен только для команд.
- Аккаунт GitHub. Хватит бесплатного.
- Платная подписка ChatGPT, на которой выдаются сбросы лимита.

## Установка

```sh
brew install keshaqaz/tap/codex-auto-resets
```

Из исходников (нужен Node 26):

```sh
git clone https://github.com/Keshaqaz/ares.git && cd ares
npm ci
npm run build:worker
node src/cli/main.mjs setup      # дальше вместо codex-auto-resets пишите node src/cli/main.mjs
```

## Первая настройка

```sh
codex-auto-resets setup
```

1. **Вход в GitHub.** Откройте ссылку, введите код и разрешите доступ. Вход сохраняется в Связке ключей, повторно его не спросят.
2. **Репозиторий.** В вашем аккаунте появится приватный репозиторий `codex-auto-resets-worker`. В нём живёт воркер.
3. **Вход в ChatGPT.** Откройте ссылку, введите код и войдите в аккаунт со сбросами. Это отдельный вход только для воркера: Codex на компьютере продолжит работать как раньше.
4. **Правила.** Выберите, когда применять сбросы (см. ниже). Enter оставляет как есть.
5. **Проверка.** CLI один раз запускает воркер и показывает итог:

   ```
   Воркер работает. Сбросов: 2, ближайший истекает 22 октября 2026 г. в 15:00 UTC.
   ```

Если `setup` прервался, просто запустите его снова: он продолжит с того места, где остановился, и ничего не потеряет.

## Правила

| Правило | По умолчанию | Что делает |
| --- | --- | --- |
| Перед истечением (в последние 8 часов) | включено | Применяет сброс, когда до его истечения остаётся меньше 8 часов. |
| Когда кончится недельный лимит | выключено | Как только воркер увидит, что недельный лимит кончился, применяет сброс с ближайшим сроком. |

Правила действуют на все сбросы сразу и работают независимо друг от друга. Изменить их можно в любой момент командой `codex-auto-resets rules`. Новые правила заработают со следующего запуска воркера.

Воркер запускается примерно раз в час, но GitHub иногда задерживает запуски на несколько часов. Поэтому срабатывание правил не привязано к точной минуте.

## Каждый день

**Проверить, что всё в порядке:**

```sh
codex-auto-resets status
```

Покажет сбросы, правила, последний запуск и последнее применение. Если что-то не так, внизу будет строка «Внимание!» с подсказкой, что делать.

**Применить сброс прямо сейчас:**

```sh
codex-auto-resets apply-now
```

Выберите сброс по номеру и подтвердите `y`. CLI дождётся воркера и напишет итог. Это может занять несколько минут. Сброс одноразовый, отменить применение нельзя.

## Если что-то сломалось

Когда запуск воркера заканчивается ошибкой, GitHub присылает письмо. Запустите `codex-auto-resets status`: в нём будет причина и что делать. Частые случаи:

| Сообщение | Что сделать |
| --- | --- |
| Воркер потерял вход в ChatGPT | `codex-auto-resets login` и войдите заново. Правила и история сохранятся. |
| Воркер выключен в GitHub | Откройте ссылку из сообщения и нажмите **Enable workflow**. |
| Воркер не запускался уже N ч | Откройте ссылку из сообщения и проверьте, что GitHub Actions работает. Обычно запуски возобновляются сами. |
| Это другой аккаунт ChatGPT | Войдите в тот аккаунт, для которого ставили воркер. Сменить аккаунт можно только переустановкой: `uninstall`, затем `setup`. |
| Установка не завершена | `codex-auto-resets setup`. |
| Воркер устарел | `codex-auto-resets upgrade`. |

## Обновление

```sh
brew upgrade codex-auto-resets
codex-auto-resets upgrade
```

Вторая команда обновляет воркер в вашем репозитории. Без неё там продолжит работать прежняя версия. Правила, история и вход в ChatGPT сохраняются.

## Удаление

```sh
codex-auto-resets uninstall
brew uninstall codex-auto-resets
```

`uninstall` попросит ещё раз войти в GitHub: на удаление репозитория нужно отдельное разрешение, и CLI его не сохраняет. Затем он отзовёт вход воркера в ChatGPT, удалит репозиторий и вход в GitHub из Связки ключей. В конце дойдите по ссылке на страницу GitHub и нажмите **Revoke**, чтобы закрыть доступ полностью.

## Что где хранится

| Где | Что |
| --- | --- |
| Связка ключей на Mac | вход в GitHub (запись `codex-auto-resets`) |
| Репозиторий `codex-auto-resets-worker` | код воркера, расписание, правила, открытая сводка (сбросы и их сроки, без входа и данных аккаунта) и зашифрованный вход воркера в ChatGPT |
| Секрет `STATE_KEY` в настройках репозитория | ключ, которым зашифрован вход воркера |

Вход в GitHub даёт CLI доступ ко всем вашим репозиториям, как у `gh`. Репозиторий воркера должен оставаться приватным: если сделать его публичным, CLI откажется с ним работать.

## Сколько это стоит

Ничего. Каждый запуск воркера засчитывается GitHub Actions как минимум за минуту, в месяц выходит до ~750 минут. На бесплатном плане GitHub даёт 2000 минут в месяц на приватные репозитории. Если в других ваших приватных репозиториях тоже работают Actions, учитывайте общий расход.
