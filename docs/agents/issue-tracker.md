# Трекер задач: локальный Markdown

Задачи и спецификации проекта хранятся в `.scratch/`.

## Соглашения

- Одна папка на функциональность: `.scratch/<feature-slug>/`.
- Спецификация: `.scratch/<feature-slug>/spec.md`.
- Задачи реализации: отдельный файл на тикет в `.scratch/<feature-slug>/issues/<NN>-<slug>.md`, с нумерацией от `01`.
- Для задач реализации состояние triage записывается строкой `Status:` в начале файла. Значения определены в `triage-labels.md`.
- Комментарии и история обсуждения добавляются в конец файла под заголовком `## Comments`.

## Существующий проект auto-reset

`.scratch/` — локальная папка, она в `.gitignore` и в публичный repo не попадает. История разработки auto-reset (карта, тикеты 01–43, research) хранится вне repo.

## Публикация в трекер

Когда навык требует опубликовать задачу или спецификацию, создайте соответствующий файл в `.scratch/<feature-slug>/`, при необходимости создав папку. Перед выбором номера задачи проверьте существующие файлы.

## Чтение задачи

Когда навык требует получить тикет, прочитайте файл по указанному пути. Если пользователь указал только номер, найдите его в `issues/` соответствующей функциональности.

## Операции wayfinder

- Карта: `.scratch/<effort>/map.md`, с разделами Notes, Decisions so far и открытыми вопросами.
- Дочерний тикет: `.scratch/<effort>/issues/NN-<slug>.md`, нумерация от `01`, вопрос в теле файла.
- Тип задаётся строкой `Type:`: `research`, `prototype`, `grilling` или `task`.
- Состояние работы задаётся строкой `Status:`: `open`, `claimed` или `resolved`. Исполнитель записывается в `Assignee:`; свободный тикет имеет `Assignee: none`.
- Зависимости задаются строкой `Blocked by: NN, NN`. Тикет разблокирован, когда все перечисленные тикеты имеют `Status: resolved`.
- Фронтир: открытые тикеты с `Assignee: none`, у которых завершены все зависимости. Если карта задаёт порядок реализации, выбирайте первый доступный по этому порядку; иначе — первый по номеру. Приоритет не создаёт новую зависимость.
- Перед началом работы установите `Status: claimed` и `Assignee:` текущего исполнителя, затем сохраните файл.
- При завершении добавьте ответ под `## Answer`, установите `Status: resolved` и добавьте краткий указатель с ссылкой в Decisions so far карты.
- Если к тикету wayfinder применяется triage, записывайте triage-метку в `Labels:`: строка `Status:` сохраняет состояние работы wayfinder. Остальные метки сохраняйте.
