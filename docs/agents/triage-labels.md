# Метки triage

Пять канонических ролей соответствуют следующим значениям в локальном трекере:

| Роль навыка | Метка в трекере | Значение |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Требуется оценка задачи ответственным за проект |
| `needs-info` | `needs-info` | Ожидается дополнительная информация от автора |
| `ready-for-agent` | `ready-for-agent` | Задача полностью описана и готова для автономного агента |
| `ready-for-human` | `ready-for-human` | Требуется реализация человеком |
| `wontfix` | `wontfix` | Задача не будет выполняться |

Когда навык указывает triage-роль, используйте значение из столбца «Метка в трекере». Место записи метки определено в `issue-tracker.md`.

Чтобы изменить названия, отредактируйте столбец «Метка в трекере».
